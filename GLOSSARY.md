# Foodiary Terraform API

Este contexto descreve a infraestrutura da API Foodiary e a sua transcrição para Terraform como laboratório de aprendizagem.

## Linguagem

**Transcrição da infraestrutura**:
Recriação, em Terraform, da infraestrutura AWS usada pela API Foodiary, preservando os contratos e o comportamento da aplicação.
_Evitar_: reescrita da API, migração funcional

**MainTable**:
Tabela DynamoDB central da API Foodiary, usada para armazenar os dados persistentes do domínio.
